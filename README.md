BazarDor 🛍️

BazarDor is a modern web application designed to provide users with a convenient and user-friendly online shopping experience. It features a responsive interface, secure authentication, and a clean design that works smoothly across mobile, tablet, and desktop devices.

Features

Responsive Design: Works seamlessly on mobile phones, tablets, laptops, and desktop screens.
User Authentication: Secure sign-up and sign-in functionality using Better Auth.
Google Login: Sign in using a Google account.
GitHub Login: Authenticate easily using a GitHub account.
Email and Password Login: Allows users to create an account and sign in using their email and password.
MongoDB Integration: Stores application data in a MongoDB database.
User-Friendly Interface: Provides a clean, modern, and easy-to-use experience.
Logout Functionality: Allows authenticated users to securely sign out.

Technologies Used
Next.js — React framework for building web applications.
React — For building interactive user interfaces.
TypeScript — For type-safe and maintainable code.
Tailwind CSS — For responsive styling and layout.
Better Auth — For authentication and session management.
MongoDB — For database management.
Google OAuth — For Google authentication.
Git & GitHub — For version control and project hosting.
Vercel — For deployment.
